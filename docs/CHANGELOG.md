# 变更记录

## 0.1.4 · 2026-09-19

- **上游基线换到 v0.2.7（aea725f2）。** 官方在 0.2.7 里把 292 票据功能整个移除了（PR #7315 曾于 2026-09-18 合入 main，随后被从历史中抹除，0.2.7 树中已无相关文件），因此本 fork 把该 PR 一并带进 overlay：现在 overlay 同时承载「官方票据功能 + 本 fork 的账号级扩展」，共 86 个文件。
- 合入原作者 wangyunjeff 的 `94068e5`「支持 STATE 无代理直连复验」，并适配本分支的多模型接口：无代理账号可直连复验，残缺路由（有 proxy_id 取不到代理）明确拒绝；已绑代理账号的指纹格式保持不变，升级不会作废仍有效的票据。附带回归测试一并移植。
- 镜像标签 `state-kit-0.2.7-0.1.4`；内置版本号 `0.2.7-state-kit.0.1.4`。

## 0.1.3 · 2026-09-19

- 采票重试改激进：每轮最多 30 次尝试（原 8 次），一轮失败后冷却 1 分钟（原 5 分钟）；到期前 10 分钟开始续期的提前量不变。原策略在 10 分钟续期窗口里只能跑两轮，遇到连续失败会在票过期后出现调度空隙。
- 401 / 403 / 429 仍会立即终止整轮并进入冷却，避免对已失效账号狂打探针。
- 镜像标签 `state-kit-0.1.3-retry`。

## 0.1.2 · 2026-09-19

- 新增全局「新账号默认开启 STATE」（默认套餐、默认目标模型）；采集循环每 6 秒认领开启后创建、已绑固定代理、未手动配置过票据的 OpenAI OAuth 账号。
- 设置键 `openai_codex_ticket_default_enabled` / `_enabled_since` / `_plan` / `_models`；API 合约快照同步更新。

## 0.1.1 · 2026-09-19

- 账号级票据支持多模型：`gpt-6-astra` 与 `gpt-5.6-sol` 各自采集、复验、注入；缺票严格拦截该模型。
- 采集任务按「账号 × 模型」登记；状态接口新增 `models` / `model_statuses`；面板改为两个复选框。
- 仅增删模型时保留未变模型的票据与 revision。

- 原作者 wangyunjeff 发布的账号级 STATE 扩展。
